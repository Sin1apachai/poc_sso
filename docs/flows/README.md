# กระบวนการทำงานของระบบ SSO

เลือกกรณีที่ต้องการอ่านจากตาราง ทุกกรณีมี Sequence diagram และ Flowchart ใน [คู่มือกระบวนการ](LOGIN-AND-SESSION.md) ส่วน URL และข้อมูลรับส่งอยู่ใน [API catalog](API-CATALOG.md)

| ID  | กระบวนการ                             | ผลลัพธ์หลัก                                      |
| --- | ------------------------------------- | ------------------------------------------------ |
| F01 | Login A/B                             | เข้าใช้งานด้วยบัญชีของระบบ                       |
| F02 | Login C                               | เข้า C และเตรียม token กลางสำหรับ SSO            |
| F03 | Login SSO A/B เมื่อยังไม่ได้เข้า C    | Login C แล้วรับ token กลางเข้าแอปปลายทาง         |
| F04 | Login SSO A/B เมื่อมี session C       | เข้าแอปตามสิทธิ์โดยไม่ถามรหัสผ่านซ้ำ             |
| F05 | ปฏิเสธการเข้าสู่ระบบ                  | แจ้งว่าไม่มีสิทธิ์ ไม่มีบัญชี หรือคำขอไม่ถูกต้อง |
| F06 | เตรียม SSO หรือส่งต่อ token ไม่สำเร็จ | แจ้งข้อผิดพลาดและให้ลองใหม่                      |
| F07 | ตรวจ session และอายุ token            | ยุติ session เมื่อ token หมดอายุหรือถูกยกเลิก    |
| F08 | Logout A/B                            | ออกจากระบบที่เปิดอยู่                            |
| F09 | Logout C                              | ยกเลิก token และ session SSO ของผู้ใช้           |
| F10 | จัดการบัญชีและสิทธิ์                  | บันทึกที่ C และให้ SSO ครั้งใหม่ใช้สิทธิ์ล่าสุด  |
| F11 | ตรวจความพร้อม C                       | ยกเลิก SSO เมื่อ C ขัดข้องครบเกณฑ์               |

ภาพรวมหน้าที่ระบบและแหล่งเก็บข้อมูลอยู่ใน [README](../../README.md) วิธีตั้งค่าอยู่ใน [คู่มือ Keycloak](../keycloak/SETUP-GUIDE.md)
